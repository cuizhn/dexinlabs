请重构 Renderer.vue，使其符合分层架构要求。

当前问题：
Renderer.vue 承担了过多非展示职责，包括：

1. 判断内容来源（contentHtml、bodyHtml、content、body 等）
2. 拼接 intro/body/summary
3. 调用 Markdown Engine 的 renderToHTML
4. 管理 markdown 异步渲染状态
5. 处理 loading 和 renderId 竞态
6. 模拟 frontmatter、toc、readingTime 数据

这些逻辑不应该存在于 Vue Renderer 组件中。

调整目标：

一、Renderer.vue 只负责展示层

它的职责：

* 接收已经处理完成的数据
* 渲染 HTML
* 提供 header/body/footer 等 slot
* 提供基础 CSS class

它不应该：

* import markdown engine
* 处理 markdown 字符串
* 判断内容字段
* 拼接内容
* 管理异步状态

二、调整后的数据流：

Content Engine
↓
Content Service / Presenter
↓
Markdown Engine
↓
Renderer.vue

三、Renderer 接收的数据应该类似：

{
html: string,
toc?: TocItem[],
frontmatter?: object,
readingTime?: number
}

四、Markdown Engine 保持独立

Renderer 不允许：

import { renderToHTML } from '@markdown'

五、删除以下逻辑：

* RenderableContent 接口
* prerenderedHtml computed
* markdownString computed
* renderId
* markdown watch
* loading 状态
* 内容格式兼容判断

六、保留：

* template 结构
* slot 设计
* theme class
* 样式系统

重构完成后，请说明：

1. 哪些代码移动到了哪个模块
2. Renderer.vue 当前职责
3. 新的数据流是否符合 Core / Data / Render 架构。
