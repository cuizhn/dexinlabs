# 认识一元一次方程

一元一次方程是代数学中最基础、最重要的概念之一。它是我们用**数学语言**描述现实世界中"等量关系"的工具。

## 什么是方程

在日常生活中，我们经常遇到"已知一些量，要求另一个量"的问题。当我们用字母表示未知数，并根据**等量关系**列出等式时，就得到了一个**方程**。

::: definition{term:方程}
含有**未知数**的**等式**叫做方程。使方程左右两边**相等**的未知数的值，叫做方程的**解**。
:::

例如：

- $2x + 3 = 7$ 是一个方程，其中 $x$ 是未知数
- 当 $x = 2$ 时，左边 $= 2 \times 2 + 3 = 7 =$ 右边，所以 $x = 2$ 是这个方程的解

::: hint{level:info}
**方程 vs 等式**：所有的方程都是等式，但并非所有等式都是方程。只有**含有未知数**的等式才是方程。例如 $3 + 5 = 8$ 是等式但不是方程。
:::

## 什么是一元一次方程

::: definition{term:一元一次方程}
只含有**一个**未知数（一元），且未知数的最高次数为 **1**（一次）的方程，叫做一元一次方程。
:::

一元一次方程的**标准形式**为：

$$ax + b = 0 \quad (a \neq 0)$$

其中 $a$、$b$ 为已知数，$x$ 为未知数。

### 判断方法

判断一个方程是否为一元一次方程，需要满足以下三个条件：

1. 只含有**一个**未知数
2. 未知数的最高次数为 **1**
3. 未知数的系数**不为零**

::: hint{level:warning}
**易错点**：$x^2 + 1 = 0$ 不是**一元一次**方程，因为未知数的最高次数是 2（这是一元二次方程）。$x + y = 3$ 也不是，因为它含有**两个**未知数。
:::

| 方程 | 是否一元一次方程 | 原因 |
|------|:-:|------|
| $3x - 1 = 8$ | ✅ | 一个未知数，次数为 1 |
| $x^2 = 4$ | ❌ | 未知数次数为 2 |
| $2x + y = 5$ | ❌ | 含有两个未知数 |
| $\frac{x}{3} + 1 = 0$ | ✅ | 可化为标准形式 |

## 解方程的基本步骤

解一元一次方程的核心思路：通过**等式的性质**，逐步将方程化为 $x = a$ 的形式。

### 等式的性质

::: definition{term:等式的性质}
1. **性质一**：等式两边同时加上（或减去）同一个数或同一个代数式，所得结果仍是等式。
2. **性质二**：等式两边同时乘以（或除以）同一个不为零的数，所得结果仍是等式。
:::

### 解题五步法

解一元一次方程的一般步骤如下：

1. **去分母**：方程两边同乘各分母的最小公倍数
2. **去括号**：利用分配律展开括号
3. **移项**：将含未知数的项移到一边，常数项移到另一边（移项要**变号**）
4. **合并同类项**：将同类项合并
5. **系数化为 1**：方程两边同除以未知数的系数

::: hint{level:tip}
**口诀记忆**：去分母、去括号、移项、合并、系数化 1 —— 五步解方程，移项要变号！
:::

## 实战演练

::: example{title:例 1}
解方程：$3x + 5 = 14$

**解：**

移项，得：

$$3x = 14 - 5$$

合并同类项，得：

$$3x = 9$$

系数化为 1，得：

$$x = 3$$

**检验**：将 $x = 3$ 代入原方程，左边 $= 3 \times 3 + 5 = 14 =$ 右边 ✅
:::

::: example{title:例 2}
解方程：$2(x - 1) = 3x + 4$

**解：**

去括号，得：

$$2x - 2 = 3x + 4$$

移项，得：

$$2x - 3x = 4 + 2$$

合并同类项，得：

$$-x = 6$$

系数化为 1，得：

$$x = -6$$

**检验**：左边 $= 2(-6 - 1) = 2 \times (-7) = -14$，右边 $= 3 \times (-6) + 4 = -18 + 4 = -14$，左边 $=$ 右边 ✅
:::

::: example{title:例 3 — 含分数的方程}
解方程：$\dfrac{x+1}{2} = \dfrac{x-1}{3} + 1$

**解：**

去分母（两边同乘 6），得：

$$3(x + 1) = 2(x - 1) + 6$$

去括号，得：

$$3x + 3 = 2x - 2 + 6$$

移项，得：

$$3x - 2x = -2 + 6 - 3$$

合并同类项，得：

$$x = 1$$

**检验**：左边 $= \dfrac{1+1}{2} = 1$，右边 $= \dfrac{1-1}{3} + 1 = 0 + 1 = 1$，左边 $=$ 右边 ✅
:::

## 课堂练习

::: question{hint:先移项，再系数化为 1}
解方程：$5x - 3 = 2x + 9$
:::

::: question{hint:先去括号，注意符号}
解方程：$3(x + 2) - 1 = 2(x - 1)$
:::

::: question{hint:先去分母，找最小公倍数}
解方程：$\dfrac{2x - 1}{3} = \dfrac{x + 2}{4}$
:::

## 本课小结

::: hint{level:info}
**核心要点回顾**

- **方程**：含有未知数的等式
- **一元一次方程**：一个未知数、次数为 1 的方程，标准形式 $ax + b = 0$
- **等式的性质**：解方程的理论基础
- **五步法**：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1
- **检验**：将求得的解代入原方程，验证左右两边是否相等
:::
